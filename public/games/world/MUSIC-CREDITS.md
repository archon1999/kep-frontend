# Game soundtrack credits

These tracks play in Keppy World. The other games use selections from the same four tracks. All MP3 files in this directory were normalized and encoded for browser playback from the creators' source audio.

| Local file | Track and creator | Source | License |
| --- | --- | --- | --- |
| `feel-good-island-loop.mp3` | “Feel Good Island Loop,” seamless edit by AntumDeluge of “Feel Good Island” by Brandon Morris | https://opengameart.org/content/feel-good-island-loop | CC0 or OGA-BY 3.0, as offered on the source page; attribution notice: Brandon Morris |
| `overworld.mp3` | “Overworld (BGM)” by IntelligentGene / Another Page Studio | https://opengameart.org/content/overworld-bgm | CC0 |
| `an-adventure.mp3` | “An Adventure” by KiluaBoy | https://opengameart.org/content/sci-fi-adventure-eastern-quiet-piano-loop | CC0 |
| `exploration-theme.mp3` | “Exploration Theme” by Cleyton Kauffman | https://opengameart.org/content/exploration-theme | CC0 |

The original `feel-good-island-loop.ogg` is retained alongside its MP3 transcode. The source page for the Brandon Morris original is https://opengameart.org/node/4797.
